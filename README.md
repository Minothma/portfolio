## 🧭 About The Project

This repository hosts the official personal portfolio of **Minothma Sithumini**, an Information Technology Undergraduate at the **University of Moratuwa** (CGPA: 3.47 / 4.00), aspiring for Software Engineering Internship opportunities.

Designed with an **Obsidian Slate & Cyber Emerald / Mint** aesthetic (`#070A0E` background, `#10B981` / `#34D399` accents), the portfolio features smooth micro-interactions, full mobile responsiveness, architecture case study modals, and an automated PDF CV generator.

---

## ✨ Key Features

- **Obsidian & Cyber Emerald UI**: Sleek dark theme with subtle emerald mesh glows and glassmorphism cards.
- **Interactive Case Studies**: Deep-dive modals for featured engineering projects showcasing system architecture diagrams, database schemas, and concurrency handling.
- **Dynamic Tech Marquee**: Smooth, GPU-accelerated infinite horizontal ticker showcasing technical proficiencies.
- **Left Scroll-Spy Rail**: Sticky desktop navigation rail tracking active sections (`ABOUT`, `WORK`, `JOURNEY`, `TOOLKIT`, `CONTACT`) with scroll progress indicators.
- **Category Filterable Projects**: Filter between Enterprise Healthcare, Full-Stack, and Embedded/IoT systems.
- **Integrated PDF CV**: High-fidelity, 2-page curriculum vitae generated using `pdf-lib`.
- **1-Click Direct Reach**: Copy-to-clipboard email action, direct WhatsApp messaging, and interactive social cards.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later installed
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Minothma/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
